# Optimization Module

## Overview
The Optimization Module is responsible for converting machine learning predictions into business decisions for the SupplyPrescript system.

## Objectives
- Apply business constraints.
- Minimize shipment cost.
- Reduce delivery delays.
- Generate optimized recommendations.
- Support closed-loop decision making.

## Inputs
- Predicted shipment delay
- Shipment cost
- Delivery priority
- Transportation mode

## Outputs
- Optimized shipment recommendation
- Cost-optimized decision
- Recommended transportation method

## Technologies
- Python
- SciPy
- NumPy
